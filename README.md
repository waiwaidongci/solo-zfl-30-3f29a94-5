# 水下考古协作调度台

离线单页应用：以遗址为单位统一管理潜次、人员、气瓶、天气与前后依赖；排班前自动检查
时间重叠、耗气、天气窗口、依赖顺序；任务按「提交 → 复核 → 批准 → 执行 → 关闭」逐级流转；
支持多人导出/导入合并、冲突标出与解决、撤销重做、全程审计留痕。桌面与手机均可完成核心流程，键盘可操作。

## 一、运行

无需构建、无需联网、无任何运行时依赖：

- **直接打开**：双击 `index.html`（`file://` 直开已验证可用）；
- **或本地静态服务**：`python3 -m http.server 8000` 后访问 `http://localhost:8000`。

首次打开自动载入演示数据（南海一号·遗址A，含 2 个潜次、3 名人员、5 只气瓶、
2 天天气窗口、1 条依赖、1 个任务）。数据保存在浏览器 `localStorage`，
`localStorage` 不可用时自动退化为内存态（刷新即清空，功能不受影响）。

## 二、功能与规则

### 排班校验（保存「已排班」潜次前强制执行，错误阻止、警告可确认后继续）
| 检查 | 规则 |
|------|------|
| 时间重叠 | 同一潜水员同日时段重叠 → 错误；同遗址时段重叠但人员不同 → 警告 |
| 耗气 | 需求 = Σ(个人SAC × (深度/10+1) × 时长 × 1.5安全系数)，超出已指派气瓶总气量 → 错误；余量 <30% → 警告；另校验个人证书深度上限 |
| 天气窗口 | 潜次须落在当日作业窗口内，且风速 ≤15节、浪高 ≤1.2m、能见度 ≥3m；无天气记录 → 警告 |
| 依赖顺序 | 前置潜次排在后面 → 错误；前置未完成 → 警告；添加依赖时拦截自环/重复/循环 |

### 任务流转
`草稿 → 提交 → 已复核 → 已批准 → 执行中 → 已关闭`，另有「退回」回到草稿。
**重复提交与跨级流转在数据层抛错拦截**（UI 同时只给出当前可执行按钮，双保险）。

### 协作与留痕
- **导出/导入合并**：导出全量 JSON；导入他人文件后按 id 合并——新增追加、相同跳过、
  不同记为冲突；冲突在排期页逐项标出，可「保留本地 / 采用对方」，审计日志取并集。
- **撤销/重做**：所有修改经 `store.commit` 入栈，Ctrl+Z / Ctrl+Shift+Z 可逐步回退与重做。
- **审计留痕**：只增不减——每次提交、撤销、重做、导入、冲突解决均留痕（时间/署名/内容），
  撤销不回滚审计。顶栏「署名」即审计与合并时的操作人。

## 三、目录结构与架构

```
index.html          页面外壳（结构占位，无业务逻辑）
css/app.css         响应式样式（桌面分栏 / 移动单栏标签，触控目标 ≥44px）
js/domain.js        领域逻辑层：排班四类校验、任务状态机、导入合并与冲突解决（纯函数，无 DOM）
js/store.js         状态容器：commit/undo/redo、审计、持久化、导入导出（无 DOM，storage 可注入）
js/ui.js            界面层：渲染与事件、键盘快捷键、焦点保持（只调 Store/Domain 接口）
js/app.js           启动引导
tests/              自动化测试（node:test，直接测数据层）
tools/browser-check.mjs   真实浏览器走查脚本（Playwright）
tools/shots/        走查截图证据
```

数据层（`domain.js`/`store.js`）与界面层（`ui.js`）完全分离：数据层不引用 DOM，
可在 Node 中直接加载测试；界面层只通过 `Store` 暴露的方法改数据，无法绕过校验与状态机。

## 四、自动化测试

**结果：24/24 通过**（Node 20 内置 test runner，零依赖）。覆盖：

  天气窗口越界与超限、依赖顺序/循环依赖拦截、任务全链路流转、
  重复提交拦截、跨级流转拦截、退回重提、合并的增/跳/冲突、冲突双向解决。

  非法 JSON 拦截、审计并集、署名写入审计。

## 六、键盘操作

| 按键 | 功能 |
|------|------|
| `Ctrl/⌘+Z` / `Ctrl/⌘+Shift+Z`（或 `Ctrl+Y`） | 撤销 / 重做 |
| `Alt+1..4` | 切换 排期/任务/资源/审计 标签 |
| `N` / `T` | 新建潜次（排期页）/ 新建任务（任务页） |
| `?` | 快捷键帮助；`Esc` 关闭弹窗 |
| `Tab` / `Shift+Tab` + `Enter`/`空格` | 全部控件可聚焦、可触发（焦点在重渲染后自动保持） |

## 七、数据格式

导出的 JSON 含 `sites`（含 personnel/cylinders/weather/dives/dependencies 子集合）、
`tasks`、`audit` 三部分，实体均以 `id` 为合并键；直接把他人的导出文件通过
「导入合并」读入即可协作，冲突项会逐条列出双方内容供选择。
